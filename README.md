# Techno Bundle — ورژن ۷

این نسخه از ساختار و موتور مالی نسخه ۶ شروع شده و قابلیت‌های جدید ورژن ۷ را اضافه می‌کند.

## تفاوت‌های واقعی ورژن ۷ نسبت به ۶
- انتخاب روش تولید در پنل مدیریت: تعیین دستی تعداد یا تولید هوشمند سناریوها
- در تولید هوشمند مدیریت، بررسی ترکیب‌های معتبر برای تعداد کارتخوان از ۱ تا سقف جست‌وجوی تنظیم‌شده و رتبه‌بندی بر اساس هدف انتخابی
- در پنل کارگزار، ورودی بودجه تنها؛ نمایش یک پیشنهاد اصلی و حداکثر یک پیشنهاد ارتقا تا ۱۰۰ میلیون تومان بیشتر، فقط اگر از نظر تعداد کارتخوان/قیمت بهتر باشد
- صفحه فرمول‌های مالی فارسی
- لوگوی PNG توسن تکنو، صفحه آغازین ۵ ثانیه‌ای، فونت یکان و نام برنامه Techno Bundle

## منطق مالی حفظ‌شده
- قیمت پیش از باندل = قیمت پایه کارتخوان + بودجه بازاریابی هر کارتخوان
- ظرفیت باندلینگ هر کش‌لس = قیمت فروش − بهای تمام‌شده − مبلغ سود/مارک‌آپ
- بودجه بازاریابی دوباره از ظرفیت باندلینگ کسر نمی‌شود
- قیمت کارتخوان از کف رقابتی پایین‌تر نمی‌رود؛ بسته‌های دارای مانده منفی نامعتبرند
